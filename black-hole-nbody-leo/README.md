# Black-hole flyby: four-body N-body dynamics seen from low Earth orbit

**Physics**: numerical mutual gravity of Sun, Earth, Moon, and a hypothetical black hole with ten solar masses. **View**: Godot 4 scene observed from a synthetic 420 km LEO-altitude camera, pointed at the black hole. All camera-relative directions, angular separations, visibility and eclipses are computed from the **same N-body state vectors as the orbital integrator**.

## What is accurate and what is illustrative

| Item | Treatment |
| --- | --- |
| Four-body trajectories | SciPy DOP853 high-tolerance Newtonian point-mass integration; sample velocities and cubic Hermite interpolation in Godot |
| Sun, Earth, Moon and black hole directions | Derived from one Cartesian frame and each sampled physical state, including observer parallax |
| Camera location | Earth-relative 420 km altitude, stabilized for continuous observation of the black hole; a **virtual observing platform**, not a propagated spacecraft orbit |
| Body occlusion by Earth | Geometric test using Earth's angular radius from 420 km |
| Celestial apparent sizes | Geometric angular radii computed from physical radii and distances |
| Display magnification | Moon and Sun ×8; black-hole shadow ×18,000; black-hole lens size ×5, **visualization enhancements** prominently labeled in the video |
| Planet surface | NASA Blue Marble day texture; NASA Black Marble night lights; NASA cloud mosaic (historical composites; **not** current weather) |
| Starfield | Artistically synthesized procedural stars and galaxy; not a measured star catalog |
| Relativity and planet destruction | No full relativistic ray tracing, gravitational-wave reaction or material/solid-body disruption. No fictional Earth destruction is added |

**Important geometry:** With the current specified encounter, the Sun is initially ~155° away from the black hole. It is physically impossible for both to appear in an ordinary 72° vertical-FOV rectilinear camera at that moment. The display therefore includes an angular sky compass and indicators for bodies outside the field of view or hidden by Earth, instead of inventing positions.

**Important physics:** The existing DOP853 initial state is *idealized*, not calibrated to an actual date via JPL Horizons; the black hole's closest approach is ~19.55 million km in the data, and maximum modeled point-mass tidal difference over the Earth is only ~2.31×10⁻⁴ g. Prior illustrative images of Earth disintegrating are **not** a physically supported result of this particular N-body scenario.

## Quick start

1. Open `black-hole-nbody-leo/project.godot` in **Godot 4.4.1+**.
2. Press F6 or F5 to play `main.tscn`.
3. Press **Space** to pause, arrows to skip 3 seconds, **1–5** for stages, **R** to restart, or drag the timeline.
4. Render screenshots with `godot --path black-hole-nbody-leo -- --capture-dir=/absolute/output/path`.
5. Render the complete 80-second video with Godot Movie Maker: `godot --path black-hole-nbody-leo --write-movie video/leo-physical.avi --fixed-fps 15 --quit-after 1200` and convert with ffmpeg.

The GitHub Actions workflow `Physical N-body LEO cinema` imports resources, validates physical sampling/camera geometry, captures screenshots from the real scene, exports AVI and converts it to H.264 MP4. Download the film from its Actions artifacts.

## Recompute trajectories

The bundled `data/four_body.csv` is reproducible, generated with:

```bash
pip install numpy scipy pillow
cd black-hole-nbody-leo
python scripts/generate_orbits.py --initial idealized --output data/four_body.csv
python scripts/make_moon.py
```

To obtain date-specific Sun/Earth/Moon initial conditions, use the generator's `--initial horizons --epoch ...` mode with JPL Horizons access. That is an **alternative** run, not what the bundled movie shows. See `data/four_body.json` for exact integrator parameters, source, conservation diagnostics and encounter geometry.
